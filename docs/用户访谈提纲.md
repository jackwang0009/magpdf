# MagPDF 用户访谈提纲

| 项 | 内容 |
|---|---|
| 版本 | v0.1 |
| 状态 | 草案，P0 第一周开始约访 |
| 日期 | 2026-11-06 |
| 负责人 | 界面组设计人员主持，测试与工程组记录并收集样本 |
| 时间 | P0 第 1–5 周 |
| 依据 | 《MagPDF 技术方案》v0.6：1.4、11.1、11.2、14.2；《P0 技术验证计划》V15 |

---

## 1. 目的

1. 验证方案 11.1 的高频工作和 11.2 的组件优先级，包括套打、标签打印、打印前条码检查。
2. 了解现在用的 PDF 编辑器、标签软件、货代管理系统和打印设备，补全竞品分析（方案 1.4）。
3. 了解谁决定买软件、能接受什么价格，为《授权与定价方案》提供依据。
4. 收集真实单证样本，按《测试样本收集与脱敏规范》处理。
5. 招募 Beta 测试用户。

## 2. 对象与安排

- 海运、空运、跨境电商（FBA 头程）货代各 2–3 家，共 6–9 家；小公司（20 人以下）和中型公司（20–100 人）至少各一家。
- 每家访谈 1–2 人：一线操作或单证人员必须有，主管或决定采购的人尽量有。
- 优先上门，看他们实际怎么处理单证；去不了的改视频访谈，请对方共享屏幕演示。
- 每次 60–75 分钟，两人一组：一人提问，一人记录。
- 录音、录屏事先征得同意；对方不同意就只做笔记。
- 每家送一份答谢礼品（预算 300 元左右），并承诺正式版优惠。

## 3. 访前准备

- 约访时说清：目的、时长、是否录音，以及会请对方提供脱敏后的单证样本。
- 带齐材料：访谈和录音同意书、样本使用同意书、保密协议；方案 8.2 的界面图（打印出来或用平板展示）；12 张功能卡片（第 5 节 E 部分）；记录模板（第 6 节）。
- 事先了解对方的主营业务和航线。

## 4. 访谈原则

- **问做过的事，不问假设**：问"你最近一次改提单是怎么做的"，不问"你会不会用这个功能"。
- **让对方演示**，少打断；多追问"为什么"、"然后呢"、"多久一次"、"出过什么问题"。
- **不推销产品**，不评价对方现在的做法。
- **价格问题放在最后问。**

## 5. 提纲

### A. 背景（5 分钟）

1. 公司主要做哪些业务？每月大概多少票？
2. 你的岗位是什么，日常负责哪些事？
3. 公司里多少人处理单证？

### B. 日常单证工作（15 分钟）

4. 请回忆最近一个工作日，你处理了哪些单证？按时间顺序讲一遍。
5. 这些单证是从哪里来的：船公司或航司的系统、客户、电商平台、自己公司的系统？什么格式：PDF、Excel、Word、纸质？
6. 拿到以后要做哪些修改？最常改的是哪些内容？
7. 一份单证从拿到到发出要多久？哪一步最耗时？
8. 最近一次因为单证出错带来的麻烦是什么？后来怎么解决的？

### C. 现在用的工具（10 分钟）

9. 改 PDF 用什么软件（Acrobat、福昕、WPS、万兴或其他）？个人买的还是公司统一买的？一年花多少钱？
10. 做标签用什么软件（BarTender、中琅、ZebraDesigner、Excel，还是货代系统自带的）？
11. 公司用哪个货代管理系统？它能出哪些单证、能打印什么？哪些做不了，只能另外处理？
12. 用哪些打印机（热敏标签打印机的型号、激光、针式）？有没有扫描枪？
13. 这些工具最让你不满意的地方是什么？

### D. 场景深挖（20 分钟，按对方业务挑着问，尽量请对方现场演示）

14. **改提单确认件、托书**：怎么改？改完别人看得出来吗？字体对不上时怎么办？
15. **盖章**：公司章、电放章怎么盖？印章图片从哪来？谁有权限盖？
16. **标签**：箱唛、进仓标签、空运标签、分拣标签怎么做？一次做多少张？数据从哪来（Excel、系统）？
17. **FBA 标签**：平台导出的标签怎么拆开、怎么打到热敏纸上？有没有因为条码扫不出被拒收或罚款？
18. **套打**：有没有在预印的提单纸、空运单、发票纸上打印？用什么打印机？对不齐时怎么调？一个月打多少份？
19. **扫描件**：收到扫描件后要做什么？需要改扫描件上的字吗？多久一次？
20. **条码**：有没有遇到条码打出来扫不出的情况？一般是什么原因？
21. **批量**：有没有按件数或按 Excel 批量出单证、标签的需要？现在怎么做？

### E. 概念测试（10 分钟）

22. 给对方看方案 8.2 的界面图，简单介绍：对象级编辑、组件、标签批量生成、打印前条码检查、套打。然后问：第一眼觉得这是做什么用的？最想先用哪个功能？哪里看不懂？
23. **功能卡片排序**：请对方从 12 张卡片里选出最需要的 5 张并排序，再选出最不需要的 2 张。

| 编号 | 卡片 |
|---|---|
| 1 | 改 PDF 里的文字 |
| 2 | 移动、删除页面上的任何元素 |
| 3 | 盖公司章和电放章 |
| 4 | 条码和二维码 |
| 5 | 箱唛、进仓标签等模板 |
| 6 | 按件数批量生成标签 |
| 7 | 按 Excel 批量生成单证 |
| 8 | 拆分平台标签并打印 |
| 9 | 打印前检查条码能不能扫 |
| 10 | 套打提单和空运单 |
| 11 | 扫描件识别文字（可搜索、可复制） |
| 12 | 修改扫描件上的文字 |

### F. 购买与部署（5 分钟）

24. 买软件由谁决定？流程是怎样的？需要开发票吗？
25. 一般是个人买还是公司统一买？公司电脑能不能自己装软件，有没有 IT 管控？能不能上外网？
26. **价格四问**（假设有一款软件能解决你刚才说的问题，按买断、一台电脑计）：
    - 多少钱会觉得太贵，不考虑？
    - 多少钱觉得有点贵，但还能接受？
    - 多少钱觉得划算？
    - 多少钱便宜到让你怀疑质量？

### G. 收尾（5 分钟）

27. 还有什么我们没问到、但你觉得重要的？
28. 能不能提供一些单证样本？（说明脱敏方式，签样本使用同意书）
29. 明年有试用版时，愿意参加 Beta 测试吗？

## 6. 记录模板

**基本信息**：公司代号（不写真名）、业务类型、规模、受访者岗位、日期、访谈人、记录人。

**高频工作**：

| 工作 | 频次 | 每次耗时 | 现在用的工具 | 痛点（尽量记原话） |
|---|---|---|---|---|
| | | | | |

**其他记录项**：
- 在用的工具和每年花费
- 套打情况：单据、打印机、月用量、对位问题
- 标签和打印：标签类型、打印机型号、条码问题
- 卡片排序结果：前 5 名依次是、最不需要的 2 张
- 价格四问的回答
- 能提供的样本
- 是否愿意参加 Beta
- 观察到的现象：对方实际的做法、临时变通的办法
- 访谈人小结：最重要的 3 个发现

## 7. 汇总与输出

- 每次访谈后 24 小时内整理完记录。
- 全部访谈结束后：把发现写成卡片分组归纳；统计功能卡片的排序（每张卡片进入前 5 的次数、平均名次）和价格四问的分布。
- 输出访谈报告（《P0 技术验证计划》V15 的交付物），内容包括：
  - 主要发现；
  - 对方案 11.1 高频工作、11.2 组件优先级的调整建议；
  - 对方案 1.4 竞品分析的补充；
  - 价格建议，输入《授权与定价方案》；
  - 样本清单和 Beta 用户名单。
- 报告在 P0 复盘会上讨论（《P0 技术验证计划》第 6 节）。

## 8. 合规

- 受访者的姓名、电话只保存在受限位置，报告里只用公司代号。
- 录音、录屏只用于整理记录，报告完成后 30 天内删除，或按同意书的约定处理。
- 单证样本按《测试样本收集与脱敏规范》处理。
