## 1. 已定的前提

方案附录 A2 已定：用离线授权文件，个人和公司都适用，不引入账号和后端。授权文件由发行方用私钥签名，软件内置公钥离线校验；公司授权写明公司名称和席位数（方案 13.4）。

本文在此基础上补齐：卖哪几个版本、怎么激活、授权文件长什么样、私钥怎么管、定什么价。

## 2. 版本划分（建议）

| 版本 | 面向 | 功能 |
|---|---|---|
| 免费版 | 所有人，试用期满后自动转为免费版 | 打开和阅读、搜索（包括 OCR 识别出的文字）、打印、页面整理（插入、删除、旋转、重排） |
| 专业版 | 处理办公文档、合同、扫描件的个人用户 | 免费版全部功能，加上：对象级编辑（选择、变换、改样式、图层）、改字、模板、基础组件（文本、日期、勾选框、图片、印章、签名、文字章）、导出 |
| 货代版 | 货代业务人员和公司 | 专业版全部功能，加上：条码和二维码、序号、箱号、提单号、空运单号、大写数量与金额、标志、骑缝章、内置标签模板、批量生成、按网格拆分、打印前条码检查、套打 |

- **试用**：安装后 14 天内货代版全部功能可用，不需要授权文件。到期后转为免费版，已保存的文件不受影响，里面的组件照常显示和打印，只是不能再修改参数。
- **离线试用的局限**：重装系统可以重新试用，这一点接受，不为此引入联网校验。
- 划分的依据：货代版功能是本产品相对通用 PDF 编辑器的差异（方案 1.4），价格应体现这部分价值；免费版让个人用户先用起来。

## 3. 授权类型

| 类型 | 说明 |
|---|---|
| 个人授权 | 授权给一个人，最多激活 2 台电脑（如办公室和家里） |
| 公司授权 | 写明公司名称，按席位计，每个席位激活一台电脑 |
| 站点授权 | 面向大客户，不绑定电脑，台数按合同约定，授权文件里写公司名称 |
| Beta 授权 | 发给 Beta 测试用户，有到期日（正式版发布后 30 天，《测试计划》第 8 节） |

所有正式授权都是**永久使用 + 1 年免费升级**：
- 买断后可以永久使用；1 年内发布的新版本（包括大版本）都能免费升级。
- 1 年后可以按原价的 50% 续一年升级；不续也能永久使用升级期内发布的最后一个版本。
- 这种方式不依赖电脑时钟：软件比较的是"本版本的发布日期"和"授权的升级截止日"，用户改系统时间没有用。

## 4. 离线激活

1. 软件生成机器码（帮助 > 授权 > 复制机器码）。
2. 用户把机器码和订单号发给发行方，渠道可以是官网表单、邮件或客服。
3. 发行方用签发工具生成授权文件（`.maglic`）发回。
4. 用户在软件里导入授权文件，软件离线校验签名和机器码。

**机器码**由三项信息分别哈希后组成：Windows 安装 ID（`MachineGuid`）、主板序列号、系统盘卷序列号。不含任何个人信息。校验时三项中有两项一致，就认为是同一台电脑，这样换硬盘或重装系统中的一项变化不需要重新激活。

**换电脑**：用户联系客服申请迁移，发行方在签发记录里登记旧机器码作废，签发新文件。离线方式无法远程停用旧电脑上的授权，靠授权协议约束；签发记录里每份授权每年迁移超过 2 次时人工审核。

## 5. 授权文件

### 5.1 格式

`.maglic` 是 UTF-8 文本，共两行：第一行是授权内容的 JSON（键按字母排序、不含空白），第二行是对第一行字节的 Ed25519 签名，Base64 编码。

```json
{"edition":"freight","expires":null,"id":"LIC-2026-000123","issued":"2026-11-06","licensee":"示例国际物流有限公司","machine":"M1-3F9A27C0-8B41D5E2-0C7716AF","product":"MagPDF","seats":1,"type":"company","upgradeUntil":"2027-11-06","ver":1}
```

| 字段 | 说明 |
|---|---|
| `ver` | 授权文件格式版本 |
| `id` | 授权编号，对应签发记录 |
| `product` | 固定为 `MagPDF` |
| `edition` | `pro` 专业版，`freight` 货代版 |
| `type` | `personal`、`company`、`site`、`beta` |
| `licensee` | 被授权人姓名或公司名称，显示在"关于"里 |
| `seats` | 席位数；每个席位的授权文件分别签发，这里记录该订单的总席位，供核对 |
| `machine` | 机器码；站点授权为空 |
| `issued` | 签发日期 |
| `upgradeUntil` | 升级截止日：发布日期不晚于这一天的版本都能使用 |
| `expires` | 到期日，只有 Beta 授权有；其他为 null |

### 5.2 校验

1. 用内置公钥验证签名；软件内置当前和下一把两把公钥，便于更换密钥。
2. `product` 为 `MagPDF`，`ver` 是软件认识的版本。
3. 机器码匹配（站点授权跳过）。
4. 本版本的发布日期（构建时写入）不晚于 `upgradeUntil`；否则提示"此授权的免费升级已于某日到期，可以继续使用某版本及以前的版本，或续费升级"。
5. 有 `expires` 的，当前日期不晚于到期日。为防止把系统时间调回去，软件记录最近一次运行的时间，系统时间比它早 48 小时以上时，这类授权视为已过期。

### 5.3 私钥与签发工具

- 签名密钥是 Ed25519 密钥对。私钥只存放在硬件安全密钥里，由两人分别保管两把备份；不进代码仓库，不放在联网的服务器上。
- 签发工具是内部命令行程序，在一台专用电脑上运行，签发时插入硬件密钥。每次签发写入签发记录：授权编号、订单号、客户、机器码、版本、日期、经办人。签发记录每天备份。
- 泄露处理：发现泄露的授权编号写进黑名单，随下一个软件版本发布；私钥泄露时启用下一把公钥对应的新私钥，并为现有客户重签授权文件。

## 6. 定价（建议区间，待 P0 访谈后拍板）

| 产品 | 建议价格 | 说明 |
|---|---|---|
| 专业版，个人授权 | 299–399 元 | 永久使用 + 1 年升级 |
| 货代版，个人或公司每席位 | 699–999 元 | 同上 |
| 公司多席位折扣 | 5 席起 9 折，20 席起 8 折 | |
| 续一年升级 | 原价的 50% | |
| 站点授权 | 按报价 | |

- 定价原则：专业版低于主流通用 PDF 编辑器的年费水平，货代版低于专业标签软件，让货代用一份软件代替两类工具（方案 1.4）。
- 竞品的实际价格和访谈中"价格四问"的结果（《用户访谈提纲》第 26 题）出来后，在本表区间内定价；结果明显超出区间时重新讨论。

## 7. 销售与交付

- **渠道**：官网下单，支持在线支付和对公转账；可开增值税普通发票和专用发票（货代公司采购一般需要）。
- **交付**：确认订单后发送安装包下载链接和激活说明，授权文件按第 4 节签发，工作日 4 小时内发出。
- **退款**：激活后 7 天内可申请全额退款，签发记录标为作废。
- **客服**：工作日在线；用户可通过帮助 > 导出诊断包把问题信息发给客服（方案 13.4）。

## 8. 软件中的实现

- **位置**：授权校验在主进程（Rust）里做，启动时校验一次，结果决定功能开关；引擎进程不处理授权。
- **功能开关**：按第 2 节的版本对照表开关功能。未授权的功能在界面上带"货代版"或"专业版"标记，点击后说明是哪个版本的功能、如何购买。
- **不联网**：授权从不联网校验；更新检查是另一回事，可以在偏好设置里关闭（方案 13.4）。
- **防破解**：只做签名校验，不做重度代码混淆，混淆的成本高、收益有限，接受一定的盗版率。
- **排期与工作量**：授权模块和签发工具约 2–3 人周，由测试与工程组负责、引擎组协助，在 P3 前半段完成，Beta 测试要用到 Beta 授权；计入附录 A1 的"测试、CI、安装包与发布"一项。
