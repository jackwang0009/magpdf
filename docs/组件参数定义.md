## 1. 用途

同一份参数定义有四个用处：
1. 引擎按参数生成 PDF 对象。
2. 属性面板按定义自动生成参数界面，新增组件不用单独写界面（方案 11.3）。
3. 参数以 JSON 存进文件（《文件私有数据格式规范》4.3）。
4. 参数界面的即时校验和批量生成前的逐行检查共用同一套校验规则（方案 11.7）。

定义写在 Rust 代码里（`engine/magpdf-components`），构建时生成 TypeScript 类型和界面描述（`packages/protocol`）。本文是定义的人读版本：要改参数，先改本文并评审，再改代码。

## 2. 参数描述格式

### 2.1 每个参数的字段

| 字段 | 说明 |
|---|---|
| `key` | JSON 键名，小驼峰 |
| `label` | 界面上的标签 |
| `type` | 参数类型（2.2） |
| `default` | 默认值 |
| `required` | 是否必填 |
| `constraints` | 取值范围、长度、正则、枚举值 |
| `unit` | 显示单位 |
| `group` | 界面分组，同组参数放在一起，可折叠 |
| `visibleWhen` | 显示条件，如 `symbology in [ean13, upca]` |
| `help` | 悬停时的说明 |

### 2.2 参数类型

| 类型 | JSON 表示 | 界面控件 |
|---|---|---|
| `string` | 字符串 | 单行输入框 |
| `text` | 字符串，可含换行 `\n` | 多行输入框 |
| `template` | 字符串，可含占位符（2.3） | 单行输入框，右侧有 `{n}` 插入按钮 |
| `int` | 整数 | 数值输入 |
| `number` | 数值 | 数值输入 |
| `length` | 数值，单位 mm | 数值输入，可切换 pt/mm/px（方案 8.3） |
| `enum` | 字符串，取值见定义 | 下拉框 |
| `bool` | `true` / `false` | 勾选框 |
| `color` | `{"space": "gray" \| "rgb" \| "cmyk", "c": [分量…]}`，分量 0–1 | 色块，点击打开颜色面板 |
| `font` | `{"family": "思源黑体", "weight": 400, "italic": false, "size": 10}`，字号单位 pt | 字体选择器 |
| `date` | `"2026-11-06"` | 日期选择器 |
| `imageRef` | `{"lib": "seal" \| "signature" \| "embedded", "sha256": "…"}` | 从印章库、签名库或文件选择 |

### 2.3 占位符

`template` 类型的参数可以引用批量生成时的变量：

| 占位符 | 含义 | 阶段 |
|---|---|---|
| `{n}` | 当前序号，按页面上序号组件的补零位数格式化；页面上没有序号组件时从 1 起、不补零 | P2 |
| `{N}` | 总数 | P2 |
| `{列名}` | 按表格批量时，当前行该列的值，如 `{PO号}` | v1.1 |

- 字面的花括号写成 `{{`、`}}`。
- 编辑时按 n = 1、N = 批量总数（没设时为 1）显示预览。
- 一页最多一个序号组件，它的格式决定这一页的 `{n}`。

### 2.4 校验结果

校验返回一组 `{severity, key, message}`：
- `error`：数据不合法，不能生成。例如 EAN-13 里有字母、箱号位数不对。
- `warning`：能生成，但可能有问题。例如模块宽度低于建议值、静区被别的对象压住。界面上组件显示警告角标（方案 8.6），不阻止保存和打印。

## 4. 各组件定义

### 4.1 `text` 文本（ver 1）

| 键 | 标签 | 类型 | 默认 | 约束与说明 |
|---|---|---|---|---|
| `content` | 内容 | template（可多行） | 空 | 必填。P1 只允许单行，P2 起可用 `\n` 手动换行 |
| `font` | 字体 | font | 思源黑体 Regular 10 pt | 嵌入许可禁止嵌入的字体不能选（方案 5.4） |
| `color` | 颜色 | color | 黑（gray 0） | |
| `align` | 对齐 | enum `left` / `center` / `right` | `left` | |
| `lineHeight` | 行距 | number | 1.2 | 字号的倍数，0.8–3；多行时有效 |
| `tracking` | 字距 | int | 0 | 千分之一 em，-200–500 |
| `boxWidth` | 框宽 | length | 0 | 0 表示不限 |
| `boxHeight` | 框高 | length | 0 | 0 表示不限 |
| `overflow` | 超出框时 | enum `none` / `shrink` / `warn` | `none` | `shrink`：逐级缩小字号（P3，方案 10.6） |
| `minSize` | 最小字号 | number | 6 | 单位 pt；`overflow` 为 `shrink` 时有效 |

- **生成**：用 HarfBuzz 塑形，新文字用 Identity-H 编码的 Type0 字体，带 ToUnicode（方案 5.3）。
- **检查**：内容为空时警告；缺字形时按方案 5.2 回退并提示"字体已替换"；缩到 `minSize` 仍超出框时报错，字段标红（方案 8.6）。

### 4.2 `date` 日期（ver 1）

| 键 | 标签 | 类型 | 默认 | 约束与说明 |
|---|---|---|---|---|
| `mode` | 取值方式 | enum `onCreate` / `fixed` | `onCreate` | `onCreate`：置入时、从模板新建时、批量生成时取当天；`fixed`：固定为 `fixedDate` |
| `fixedDate` | 日期 | date | 当天 | `mode` 为 `fixed` 时显示 |
| `format` | 格式 | enum | `YYYY-MM-DD` | 见下表 |
| `font`、`color`、`align` | | | | 同 4.1 |

| `format` 取值 | 示例 |
|---|---|
| `YYYY-MM-DD` | 2026-11-06 |
| `MMM. DD, YYYY` | NOV. 06, 2026 |
| `DD MMM YYYY` | 06 NOV 2026 |
| `DD/MM/YYYY` | 06/11/2026 |
| `MM/DD/YYYY` | 11/06/2026 |
| `YYYY年M月D日` | 2026年11月6日 |

英文月份一律用大写的三字母缩写；五月写 `MAY`，不加点。

`onCreate` 不会在打开文档时自动改日期，否则一打开文档就变成"已修改"，也改变了已开出单据的内容。

### 4.3 `checkbox` 勾选框（ver 1）

| 键 | 标签 | 类型 | 默认 | 约束与说明 |
|---|---|---|---|---|
| `state` | 状态 | enum `empty` / `cross` / `check` | `empty` | |
| `label` | 说明文字 | string | 空 | 如 `FREIGHT PREPAID` |
| `labelSide` | 文字位置 | enum `right` / `left` | `right` | |
| `boxSize` | 框边长 | length | 3.5 | 2–10 mm |
| `lineWidth` | 线宽 | length | 0.25 | mm |
| `font`、`color` | | | 思源黑体 8 pt；黑 | 同 4.1 |

### 4.4 `image` 图片（ver 1）

| 键 | 标签 | 类型 | 默认 | 约束与说明 |
|---|---|---|---|---|
| `src` | 图片 | imageRef（`embedded`） | — | 必填；PNG（保留透明）、JPEG |
| `width` | 宽 | length | 按图片 DPI 换算，没有 DPI 信息时按 150 dpi | |
| `height` | 高 | length | 同上 | |
| `keepRatio` | 保持比例 | bool | `true` | |
| `compress` | 压缩 | enum `original` / `jpeg80` | `original` | `original`：PNG 用无损压缩，JPEG 原样嵌入 |

- **检查**：按置入尺寸算出的分辨率低于 150 dpi 时警告"图片可能模糊"。

### 4.5 `serial` 序号（ver 1，P2）

| 键 | 标签 | 类型 | 默认 | 约束与说明 |
|---|---|---|---|---|
| `format` | 格式 | template | `C/NO. {n}/{N}` | 必须含 `{n}`；常用格式：`{n} OF {N}`、`{n}/{N}`、`NO. {n}` |
| `start` | 起始值 | int | 1 | ≥ 0 |
| `step` | 步长 | int | 1 | ≥ 1 |
| `pad` | 补零位数 | int | 0 | 0–8；3 表示 001。只作用于 `{n}`，`{N}` 不补零 |
| `total` | 总数 | int | 1 | 批量生成时由批量对话框填入 |
| `preview` | 预览序号 | int | 1 | 只影响编辑时的显示 |
| `font`、`color`、`align` | | | | 同 4.1 |

批量生成的第 k 张（k 从 0 起）取 n = `start` + k × `step`。

### 4.6 `barcode1d` 一维码（ver 1）

| 键 | 标签 | 类型 | 默认 | 约束与说明 |
|---|---|---|---|---|
| `symbology` | 码制 | enum `code128` / `gs1-128` / `code39` / `ean13` / `upca` / `itf14` | `code128` | P1 只有 `code128` |
| `content` | 内容 | template | — | 必填，按码制校验（第 5 节） |
| `moduleWidth` | 模块宽度 | length | 0.375 | 生成时按 `printerDpi` 取整到整数个打印点（方案 11.5） |
| `barHeight` | 条高 | length | 12 | |
| `quietZone` | 静区 | enum `auto` / `custom` | `auto` | `auto` 按码制最小值（第 5 节） |
| `quietZoneWidth` | 静区宽度 | length | — | `quietZone` 为 `custom` 时显示，不得小于码制最小值 |
| `showText` | 显示可读文字 | bool | `true` | |
| `textFont` | 可读文字字体 | font | 思源黑体 8 pt | |
| `printerDpi` | 打印机分辨率 | enum `203` / `300` / `600` / `none` | `203` | `none` 表示不取整 |
| `checkDigit` | 自动计算校验位 | bool | `true` | EAN-13、UPC-A、ITF-14 少输一位时自动补；Code 39 为可选的模 43 校验 |
| `wideRatio` | 宽窄比 | number | 2.5 | Code 39、ITF-14 有效，2–3 |
| `bearer` | 保护框 | enum `none` / `frame` / `topBottom` | `frame` | 只对 ITF-14 |
| `gs1Parens` | 可读文字中应用标识符加括号 | bool | `true` | 只对 GS1-128 |

- **生成**：调用 Zint 的矢量输出，全部条合成一个填充路径，可读文字是文字对象。生成后按 `printerDpi` 渲染，用 ZXing-C++ 回读，解出的内容必须与输入一致（方案 11.5）。
- **检查**（模块宽度和条高的建议值以 GS1 通用规范现行版本为准，下表是默认配置）：

| 码制 | 建议最小模块宽度 | 建议最小条高 |
|---|---|---|
| EAN-13、UPC-A | 0.264 mm（标准尺寸的 80%） | 18.3 mm |
| ITF-14 | 0.495 mm | 32 mm |
| GS1-128（物流标签，如 SSCC） | 0.495 mm | 32 mm |
| Code 128、Code 39（非 GS1） | 0.25 mm（203 dpi 打印机 2 个点） | 6.35 mm 或符号宽度的 15%，取大者 |

此外还检查：条为红色或浅色、底色不是浅色、旋转角度不是 90° 的倍数、有斜切、其他对象压进静区（方案 11.5）。

### 4.7 `barcode2d` 二维码（ver 1）

| 键 | 标签 | 类型 | 默认 | 约束与说明 |
|---|---|---|---|---|
| `symbology` | 码制 | enum `qr` / `datamatrix` / `pdf417` | `qr` | P1 只有 `qr` |
| `content` | 内容 | template | — | 必填；长度上限由码制、版本、纠错等级决定 |
| `ecLevel` | 纠错等级 | enum `L` / `M` / `Q` / `H` | `M` | 只对 QR 码 |
| `pdf417Ec` | 纠错级别 | enum `auto` / `0`–`8` | `auto` | 只对 PDF417 |
| `moduleSize` | 模块尺寸 | length | 0.5 | 按 `printerDpi` 取整 |
| `quietZoneModules` | 静区（模块数） | int | QR 码 4，Data Matrix 1，PDF417 2 | 不得小于默认值 |
| `version` | 版本 | enum `auto` / `1`–`40` | `auto` | 只对 QR 码 |
| `dmShape` | 形状 | enum `square` / `rect` | `square` | 只对 Data Matrix |
| `gs1` | GS1 模式 | bool | `false` | 内容按 GS1 应用标识符编码；Data Matrix、QR 码有效 |
| `printerDpi` | 打印机分辨率 | enum | `203` | 同 4.6 |

- **生成**：内容含非 ASCII 字符时按 UTF-8 编码并加 ECI。生成后同样回读验证。
- **检查**：模块尺寸小于 0.3 mm 时警告；内容超出所选版本的容量时报错。

### 4.8 `seal` 印章（ver 1）

| 键 | 标签 | 类型 | 默认 | 约束与说明 |
|---|---|---|---|---|
| `src` | 印章 | imageRef（`seal`） | — | 必填，来自印章库（方案 11.6） |
| `shape` | 类型 | enum `round` / `oval` / `square` / `other` | `round` | 决定默认尺寸 |
| `width` | 宽 | length | 圆形 40，椭圆 40，方形 20 | |
| `height` | 高 | length | 圆形 40，椭圆 30，方形 20 | `keepRatio` 时随宽度变化 |
| `keepRatio` | 保持比例 | bool | `true` | |
| `opacity` | 不透明度 | number | 0.95 | 0.3–1 |

- **生成**：带透明通道的图像（软蒙版），图形状态设正片叠底（`/BM /Multiply`），下面的文字透得出来（方案 11.6）。
- 设了密码的印章，置入时要输入密码（P3）。盖到文档里的印章就是普通图像，密码只保护印章库里的文件。

### 4.9 `signature` 签名（ver 1）

与 `seal` 相同，区别是 `src` 来自签名库、没有 `shape`，`width` 默认 30 mm、高度按比例。

| `padding` | 内边距 | length | 2 | mm |
| `opacity` | 不透明度 | number | 0.9 | |
| `multiply` | 正片叠底 | bool | `true` | |

| `preset` | 文字 | 默认显示日期 |
|---|---|---|

### 4.11 `seamseal` 骑缝章（ver 1，P2）

| 键 | 标签 | 类型 | 默认 | 约束与说明 |
|---|---|---|---|---|
| `src` | 印章 | imageRef（`seal`） | — | 必填 |
| `pages` | 页码范围 | string | 全部 | 如 `1-5` |
| `edge` | 盖在哪一边 | enum `right` / `left` | `right` | |
| `width` | 印章完整宽度 | length | 40 | |
| `top` | 距页面顶部 | length | 页面高度的一半减去印章高度的一半 | |

- **生成**：印章按页数切成竖条，每页一片，贴在所选边缘；各片是同一组件的分片，共用 `/GID`，`/Part` 依次为 `1/n` 到 `n/n`（《文件私有数据格式规范》4.2）。每片都存完整参数。
- **检查**：每片宽度小于 1.5 mm 时警告"页数太多，骑缝章难以辨认"。
- 删除其中一片时，询问是否删除全部分片。

### 4.13 `blno` 提单号（ver 1，P2）

| 键 | 标签 | 类型 | 默认 | 约束与说明 |
|---|---|---|---|---|
| `number` | 提单号 | string | — | 必填；4–20 位大写字母或数字 |
| `label` | 前缀文字 | string | `B/L NO.` | 可清空 |
| `barcode` | 条码 | enum `none` / `code128` / `qr` | `none` | |

## 5. 各码制的数据规则

| 码制 | 允许的字符与长度 | 校验位 | 最小静区 |
|---|---|---|---|
| Code 128 | ASCII 0–127，建议不超过 48 个字符 | 自动计算，不显示 | 10 倍模块宽度 |
| GS1-128 | 按应用标识符输入，如 `(00)069012340000000016`；由 Zint 检查应用标识符格式 | 符号校验自动；SSCC、GTIN 等数据本身的校验位按 GS1 规则检查 | 10 倍模块宽度 |
| Code 39 | `0-9 A-Z - . 空格 $ / + %` | 可选模 43 | 10 倍模块宽度 |
| EAN-13 | 12 位或 13 位数字 | 第 13 位，GS1 模 10 | 左 11 倍、右 7 倍模块宽度 |
| UPC-A | 11 位或 12 位数字 | 第 12 位，GS1 模 10 | 左右各 9 倍模块宽度 |
| ITF-14 | 13 位或 14 位数字 | 第 14 位，GS1 模 10 | 10 倍模块宽度 |
| QR 码 | 任意文本，非 ASCII 按 UTF-8 加 ECI | 由纠错码保证 | 4 个模块 |
| Data Matrix | 任意文本；GS1 模式按应用标识符 | 由纠错码保证 | 1 个模块 |
| PDF417 | 任意文本 | 由纠错码保证 | 2 个模块 |

GS1 模 10、ISO 6346、空运单号模 7 等算法和例子见《货代业务规则》第 1 节。

## 6. 批量生成前的逐行检查

批量生成前（方案 11.7），每一张都用本文的校验规则检查一遍：按序号批量时逐个序号检查，按表格批量（v1.1）时逐行检查。有 `error` 的列出行号（或序号）、字段和原因，可以改完重试或跳过；`warning` 汇总显示，不阻止生成。
